# Ocean bottom seismograph location using MCMC algorithm  
#### The ocean bottom seismograph (OBS) is a powerful device for acquiring marine seismic data. However, the accurate location is inaccessible due to the OBS deployment method. Additionally, because there is no external GPS timing, clock drift is quite common. MCMC-OBSLoc uses Markov Chain Monte Carlo algorithms (Metropolis and Gibbs) to estimate OBS location and time correction from travel times of direct water waves.  
For more details, see the following paper:  
Hu, H., Niu, X., Wang, W., Xu, W., Ruan, A., Gong, W., Wei, X., Xu, M., Li, T., 2025. Ocean bottom seismograph relocation and time correction using the MCMC algorithm. Acta Oceanolog. Sin. 44, 101–111. https://doi.org/10.1007/s13131-025-2540-y
