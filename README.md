# Ocean bottom seismograph location using MCMC algorithm

## Ocean bottom seismograph (OBS) is a powerful equipment for marine seismic data acquisition. However, accurate location is inaccessible because of the operation of OBS deployment. Additionally, due to no external GPS timing, clock drift is quite commom. MCMC-OBSLoc uses Markov Chain Monte Carlo algorithms (Metropolis and Gibbs) to estimate OBS location and time correction from travel times of direct water waves.
